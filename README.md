# Tic Tac Toe Game in Java

## About the Project
This is a simple Tic Tac Toe game developed using Core Java. Two players, Bob and Sneha, take turns to play the game.

## Technologies Used
- Java
- Eclipse IDE

## How to Play
- Bob plays with **X**.
- Sneha plays with **O**.
- Enter the row and column numbers between `0` and `2`.
- The player who matches three symbols in a row, column, or diagonal wins.
- If all 9 positions are filled and nobody wins, the match ends in a draw.

## How to Run
1. Open the project in Eclipse IDE.
2. Open `TicTacToe.java`.
3. Run the program as a **Java Application**.
4. Follow the instructions displayed in the console.

## Concepts Used
- Variables and data types
- Two-dimensional arrays
- Loops
- If-else statements
- Methods
- User input using `Scanner`
